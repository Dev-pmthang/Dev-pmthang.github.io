Projects

Forklift Battery Protection Controller
Industrial Lithium Battery Protection Controller (04/2026 - Present)

Designed a custom protection controller PCB for electric forklift lithium battery systems, using the ESP32-S3 as the main MCU. The controller communicates with the BMS over CAN Bus and RS485 to monitor voltage, current, SOC, SOH, temperature, and active alarm status in real time.

When battery conditions fall below configured thresholds, the system drives relays to disable fork lifting and lowering while still allowing the vehicle to return to the charging station safely. A local SPI display, EEPROM-based history logging, and a web configuration interface support threshold tuning, fault tracing, and reliable operation in EMI/EMC-sensitive industrial environments.

Technology & Engineering:
ESP32-S3 CAN Bus RS485 SPI Display EEPROM Relay Control Web Server Altium Designer EMI/EMC PCB Design Embedded Firmware
