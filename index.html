Projects

Forklift Battery Protection Controller
Industrial Lithium Battery Protection Controller (04/2026 - Present)

Designed a custom protection controller PCB for electric forklift lithium battery systems, using the ESP32 as the main MCU. The controller communicates with the BMS over CAN Bus and RS485 to monitor voltage, current, SOC, SOH, temperature, and active alarm status in real time.

When battery conditions fall below configured thresholds, the system drives relays to disable fork lifting and lowering while still allowing the vehicle to return to the charging station safely. A local SPI display, EEPROM-based history logging, and a web configuration interface support threshold tuning, fault tracing, and reliable operation in EMI/EMC-sensitive industrial environments.

Technology & Engineering:
ESP32-S3 CAN Bus RS485 SPI Display EEPROM Relay Control Web Server Altium Designer EMI/EMC PCB Design Embedded Firmware

Smart Industrial Valve Controller
Industrial Valve Actuation Controller (03/2025 - Present)

Designed schematics and 4-layer PCB layouts for an industrial valve controller with AGND/DGND separation, EMI/EMC-conscious routing, ESD protection, and robust 4-20 mA / 0-10 V interfaces for noise-tolerant operation in factory environments. I also designed the H-Bridge motor driver stage for precise stepper motor actuation, covering direction control, current handling, and protection circuitry for reliable field operation.

Developed the embedded firmware on STM32 using HAL and FreeRTOS, implementing PID control, encoder feedback, Kalman filtering, ADC processing, EEPROM wear-leveling, self-diagnostics, and industrial communications over RS485 Modbus RTU, SPI, I2C, and UART with CRC checking. I supported end-to-end testing and deployment at TS FOOD factory, including HMI/PLC configuration, valve calibration, motor tuning, and operational acceptance testing, while continuing to develop V2 with enhanced monitoring and control capabilities.

Vehicle Navigation Display
Low-Power Vehicle Navigation Display with QSPI High-Brightness Screen

This project is a compact navigation display system designed for vehicle applications. I designed a custom 4-layer PCB based on EMI/EMC design practices, focusing on signal integrity, stable power distribution, noise reduction, and reliable operation in mobile environments.
